### Analysis

To reproduce the analysis reported in the manuscript and the supplementary material open the file `supplement.Rmd` and run the respective code snippets from top to bottom. Whenever additional scripts need to be run, this is noted in the respective snippet and the script itself is included in this folder.

To access the syntax to reproduce the SEM models in MPlus, open the `.out` files in the folder `./outputs` using a text editor.

The numbers reported in the paper and the supplement can be reproduced without re-running the models (SEM or otherwise) by loading files that contain selected model outputs.
